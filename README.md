# Healthcare+ E-Pharmacy Web Application

## 🚀 Overview
A full-stack web application for online medicine ordering and healthcare services.

## 💻 Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Django
- Database: MySQL

## 🔥 Features
- User Authentication (Login/Signup)
- Product Listing & Search
- Add to Cart functionality
- Dynamic UI updates
- Address storage using Local Storage

## 📌 Future Improvements
- Payment Integration
- Order Tracking System
